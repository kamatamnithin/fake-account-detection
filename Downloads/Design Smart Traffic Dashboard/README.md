
  # Design Smart Traffic Dashboard

  This is a code bundle for Design Smart Traffic Dashboard. The original project is available at https://www.figma.com/design/khqICITW4nGO0xIWxUO476/Design-Smart-Traffic-Dashboard.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.  
  ## Backend (Supabase) setup
  The application ships with a Supabase Edge Function that implements
  all of the backend routes (auth, violations, detections, analytics,
  etc.) using a simple key‑value table (`kv_store_9cc3504b`).

  ### 1. Create a Supabase project
  1. Go to https://supabase.com and create a free project.
  2. Create a table named `kv_store_9cc3504b` with the schema from
     `supabase/functions/server/kv_store.tsx` (the autogenerated
     schema is in the file header).

  ### 2. Deploy the edge function
  Install the Supabase CLI (https://supabase.com/docs/guides/cli) and
  run from the repository root:
  ```bash
  supabase login            # authenticate if you haven't already
  supabase link --project-ref <your-project-id>
  supabase functions deploy server --project-ref <your-project-id>
  ```

  Make sure the function's environment variables are set in the
  Supabase dashboard:
  * `SUPABASE_URL` – your project's URL
  * `SUPABASE_SERVICE_ROLE_KEY` – service role key (never expose on
    the client)

  ### 3. Configure the front end
  Edit `utils/supabase/info.tsx` and replace the placeholder values with
  your own `projectId` and `publicAnonKey` (from the client API keys
  section of the Supabase dashboard).

  Alternatively you can export those values via environment variables
  and modify the file accordingly.

  ### 4. Local development (optional)
  To run the database and function locally:
  ```bash
  supabase start
  # then from another shell
  npm run dev
  ```

  The front end will automatically fall back to mock data if the
  backend is unreachable, so you can work offline.
